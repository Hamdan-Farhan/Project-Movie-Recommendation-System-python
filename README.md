
🎬 Decision Tree Movie Recommendation System

A simple Machine Learning project that recommends movies using a Decision Tree Classifier based on user preferences.

🎯 Project Idea

This system predicts a movie recommendation based on:

Genre
Duration
Age rating

It learns patterns from a small dataset and suggests the most suitable movie.

🛠️ Technologies Used

Python
NumPy
Matplotlib
Scikit-learn (DecisionTreeClassifier)


▶️ How to Run

python movie_recommender.py

🧩 Features

Simple movie recommendation system
Machine learning with Decision Trees
Visual explanation of decisions
Easy-to-understand categorical encoding


🎯 Learning Outcomes

Understand Decision Tree classifiers
Learn how ML models make predictions
Practice feature encoding
Build a basic recommendation system


🏁 Conclusion

This project demonstrates how machine learning can be used to build a simple recommendation system based on user preferences.
